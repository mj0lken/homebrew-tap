# mj0lken/homebrew-tap

Homebrew casks by [mj0lken](https://github.com/mj0lken).

```bash
brew install --cask mj0lken/tap/thumbs-out
brew install --cask mj0lken/tap/tjuv
```

| Cask | Description |
|------|-------------|
| [thumbs-out](https://mj0lken.github.io/thumbs-out/) | Keeps your Mac awake while AI coding agents run commands |
| [tjuv](https://mj0lken.github.io/tjuv/) | Physical 800 Hz motion-sensing thief alarm for Apple Silicon MacBooks |
